# Docs

This directory contains working notes, design sketches, trackers, and experiment notes.

Files here are not automatically source of truth. A note may be:

- exploratory
- partially implemented
- superseded
- implemented differently
- kept for historical context

Treat code, tests, runtime API docs, and current config as source of truth unless this README marks a document as current.

## Current documents

These are kept up to date and may be read as documentation rather than as a note:

- `plugin-architecture.md` — the plugin architecture: the as-built contract, the phase
  boundaries, the accepted debt, and the decisions with the alternatives that were rejected.
  The code remains the source of truth for the implementation; this document is where the
  reasoning and the scope boundaries live.
